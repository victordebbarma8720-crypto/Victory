FONO App Download and Installation Guide

Download the FONO app (Android APK), install it safely, register with referral code ALFVVDRU and set up as a host or agency.

Published 2 November 20265 min readBased on the FONO Policy dated 08 December 2025

Before you can work as a FONO host or agency, you need the FONO app on your phone. The download link on this website is the Android APK file: Fono.apk. Use the button below, then register with referral code ALFVVDRU.

DOWNLOAD FONO APPReferral code: ALFVVDRU

How to download the FONO app

  1. Tap Download FONO App (or any Join as Host / Join as Agency button on this site – they all download the same app).
  2. A popup shows the referral code ALFVVDRU. Copy it, then tap Continue to download.
  3. Wait for Fono.apk to finish downloading.

Installing an APK file safely

Because the app is installed from an APK file, Android may show a warning the first time. Open the file, and if asked, allow installation from your browser or file manager for this file. Keep these safety points in mind:

  • Download only from the link on this website. APK copies shared in groups or on other websites may be modified.
  • APK files work on Android phones. They cannot be installed on iPhone.
  • After installing, you can switch the “install unknown apps” permission off again in Android settings.

Installing and setting up

Permissions

A video and audio calling app will reasonably ask for camera and microphone access. Be cautious if an app asks for permissions that have nothing to do with calls.

Registering as a host

After installing, register as a host and enter referral code ALFVVDRU. According to the FONO Policy dated 08 December 2025, you do not need a profile picture or audition video, but you must enter your personal PAN card number. See how to become a Fono Host.

Registering under an agency

If an agency invited you, register under that agency only – the policy allows one agent per streamer.

After installing

  • Learn the call rates for each level.
  • Understand the withdrawal thresholds and timings.
  • Keep the app updated to get the latest features and fixes.
